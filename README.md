# Jumbo-Holdsworth Trail Race

Website for the [Jumbo-Holdsworth Trail Race](https://jumbo-holdsworth.co.nz), a mountain race in the Tararua Forest Park, near Masterton, New Zealand.

The site is plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

## Run it locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Structure

```
index.html            Home
event-info.html       The races: courses, race day, categories, gear, aid stations, location, rules
enter.html            Entry fees, terms and refunds
faq.html              FAQ
volunteer.html        Volunteering
results.html          Results 1995–2026
course-records.html   Course records
assets/css/style.css  Styles
assets/js/main.js     Mobile menu, photo strip, footer year
images/               Photos and sponsor logos
content/              PDFs: course maps, race information packs, results
```

Page file names and image paths match the long-standing live site, so please don't rename them. Existing links and search results depend on them.
